# E-Library Management System

A simple front-end mini project for managing and borrowing books online.

## Features
- Search books by title, author or category
- Display available books
- Borrow books
- View borrowed books
- Return books
- Browser Local Storage

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. Search for a book and use Borrow Book / Return.
